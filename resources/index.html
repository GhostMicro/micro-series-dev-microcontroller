    แหล่งเรียนรู้เพิ่มเติม (Official Resources)¶

    รวบรวมลิงก์สำคัญจากผู้ผลิตบอร์ดทั้ง 4 ตระกูล และเครื่องมือที่จำเป็นสำหรับการพัฒนาครับ

    🔵 1. Arduino (The Legend)¶

    • เว็บไซต์หลัก: arduino.cc
    • เอกสารการเรียนรู้ (Documentation): docs.arduino.cc
    • ซอฟต์แวร์ (Arduino IDE): ดาวน์โหลดที่นี่
    • Arduino Cloud: create.arduino.cc

    🟢 2. ESP32 (Connectivity King)¶

    • เว็บไซต์ผู้ผลิต (Espressif): espressif.com
    • หน้าทรัพยากร ESP32: Espressif Resource Page
    • คู่มือการเขียนโปรแกรม (ESP-IDF): ESP-IDF Programming Guide
    • ESP32 Arduino Core: GitHub Repository

    🔴 3. STM32 (Industrial Standard)¶

    • เว็บไซต์ผู้ผลิต (STMicroelectronics): st.com
    • STM32 Developer Zone: ST MCU Developer Zone
    • เครื่องมือพัฒนา (STM32CubeIDE): ดาวน์โหลดที่นี่
    • ST Community: community.st.com

    🍓 4. Raspberry Pi (Mini PC)¶

    • เว็บไซต์หลัก: raspberrypi.com
    • เอกสารอย่างเป็นทางการ: raspberrypi.com/documentation
    • Raspberry Pi OS / Imager: ดาวน์โหลดที่นี่
    • ข่าวสารและโปรเจกต์: raspberrypi.org

    🛠️ เครื่องมือและบริการอื่นๆ¶

    • Thonny Python IDE: thonny.org (สำหรับ Raspberry Pi & MicroPython)
    • Blynk IoT Platform: blynk.io (สำหรับงาน IoT)
    • LINE Notify: notify-bot.line.me (สำหรับการแจ้งเตือน)
    • Wokwi Simulator: wokwi.com (จำลองวงจรบนเว็บ)

    Tip: หากต้องการค้นหาคำถามเฉพาะทาง แนะนำให้ค้นหาใน Stack Overflow หรือ GitHub Issues ของไลบรารีนั้นๆ จะได้คำตอบที่รวดเร็วที่สุดครับ!
