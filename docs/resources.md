# แหล่งเรียนรู้เพิ่มเติม (Official Resources)

รวบรวมลิงก์สำคัญจากผู้ผลิตบอร์ดทั้ง 4 ตระกูล และเครื่องมือที่จำเป็นสำหรับการพัฒนาครับ

---

## 🔵 1. Arduino (The Legend)

- **เว็บไซต์หลัก:** [arduino.cc](https://www.arduino.cc/)
- **เอกสารการเรียนรู้ (Documentation):** [docs.arduino.cc](https://docs.arduino.cc/)
- **ซอฟต์แวร์ (Arduino IDE):** [ดาวน์โหลดที่นี่](https://www.arduino.cc/en/software)
- **Arduino Cloud:** [create.arduino.cc](https://create.arduino.cc/)

## 🟢 2. ESP32 (Connectivity King)

- **เว็บไซต์ผู้ผลิต (Espressif):** [espressif.com](https://www.espressif.com/)
- **หน้าทรัพยากร ESP32:** [Espressif Resource Page](https://www.espressif.com/en/products/socs/esp32)
- **คู่มือการเขียนโปรแกรม (ESP-IDF):** [ESP-IDF Programming Guide](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/)
- **ESP32 Arduino Core:** [GitHub Repository](https://github.com/espressif/arduino-esp32)

## 🔴 3. STM32 (Industrial Standard)

- **เว็บไซต์ผู้ผลิต (STMicroelectronics):** [st.com](https://www.st.com/)
- **STM32 Developer Zone:** [ST MCU Developer Zone](https://www.st.com/en/microcontrollers-microprocessors/stm32-32-bit-arm-cortex-mcus.html)
- **เครื่องมือพัฒนา (STM32CubeIDE):** [ดาวน์โหลดที่นี่](https://www.st.com/en/development-tools/stm32cubeide.html)
- **ST Community:** [community.st.com](https://community.st.com/)

## 🍓 4. Raspberry Pi (Mini PC)

- **เว็บไซต์หลัก:** [raspberrypi.com](https://www.raspberrypi.com/)
- **เอกสารอย่างเป็นทางการ:** [raspberrypi.com/documentation](https://www.raspberrypi.com/documentation/)
- **Raspberry Pi OS / Imager:** [ดาวน์โหลดที่นี่](https://www.raspberrypi.com/software/)
- **ข่าวสารและโปรเจกต์:** [raspberrypi.org](https://www.raspberrypi.org/)

---

## 🛠️ เครื่องมือและบริการอื่นๆ

- **Thonny Python IDE:** [thonny.org](https://thonny.org/) (สำหรับ Raspberry Pi & MicroPython)
- **Blynk IoT Platform:** [blynk.io](https://blynk.io/) (สำหรับงาน IoT)
- **LINE Notify:** [notify-bot.line.me](https://notify-bot.line.me/) (สำหรับการแจ้งเตือน)
- **Wokwi Simulator:** [wokwi.com](https://wokwi.com/) (จำลองวงจรบนเว็บ)
