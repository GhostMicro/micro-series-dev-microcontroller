# ตอนที่ 3: ESP32: มหาอำนาจแห่ง IoT (ตอนที่ 1)

เข้าสู่โลกของ IoT ด้วย ESP32 บอร์ดที่เป็นที่นิยมที่สุดสำหรับงานเชื่อมต่อไร้สาย

## เนื้อหาในตอนนี้

- แนะนำบอร์ด ESP32 ตระกูลต่างๆ
- การติดตั้ง Board Manager ใน Arduino IDE
- การต่อเซนเซอร์เบื้องต้น (Digital & Analog Input)

---

> [!TIP]
> ESP32 มีทั้ง Wi-Fi และ Bluetooth ในตัว ทำให้มันเป็นหัวใจหลักของโปรเจกต์ IoT เกือบทุกชนิด
