# ตอนที่ 2: Arduino Uno R4: จุดเริ่มต้นของทุกคน

ทำความรู้จักกับบอร์ดมาตรฐานที่พัฒนาขึ้นมาจากตำนานอย่าง Uno R3 สู่ประสิทธิภาพที่สูงขึ้นด้วย Arduino Uno R4

## เนื้อหาในตอนนี้

- ทำความรู้จัก Arduino Uno R4 (Minima vs WiFi)
- การติดตั้ง Arduino IDE 2.x
- เขียนโปรแกรมไฟกระพริบ (Blink) ครั้งแรก

---

> [!NOTE]
> Arduino Uno R4 ใช้ขุมพลัง Renesas RA4M1 (32-bit Arm Cortex-M4) ซึ่งแรงกว่า R3 เดิมมาก!
