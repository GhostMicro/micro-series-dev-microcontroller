# เกี่ยวกับเรา (About Us)

ซีรีส์ "Roadmap นักพัฒนา Microcontroller (จากศูนย์สู่มือโปร)" นี้ถูกสร้างขึ้นเพื่อแบ่งปันความรู้ด้านระบบฝังตัวให้กับชุมชนนักพัฒนาชาวไทย

## วัตถุประสงค์

- เพื่อสนับสนุนการเรียนรู้ด้านฮาร์ดแวร์และซอฟต์แวร์
- เพื่อเป็นแหล่งอ้างอิงสำหรับผู้ที่ต้องการเริ่มต้นศึกษา Microcontroller
- เพื่อสร้างชุมชนนักพัฒนาที่พร้อมจะสร้างสรรค์นวัตกรรมใหม่ๆ

---

## ขั้นตอนการทำงาน (GitHub Deployment Flow)

เพื่อให้การอัปเดตข้อมูลเป็นไปอย่างรวดเร็ว เราใช้ระบบ CI/CD ในการ Deploy เว็บไซต์อัตโนมัติ ดังนี้ครับ:

```mermaid
graph LR
    A[นักพัฒนาแก้ไขไฟล์] --> B[Git Push ไปที่ GitHub]
    B --> C{GitHub Actions}
    C -->|Build| D[MkDocs Build]
    D --> E[Deploy ไปยัง GitHub Pages]
    E --> F((เว็บไซต์ออนไลน์))
```

> [!NOTE]
> ทันทีที่คุณทำการ Push Code ไปที่ Repository ตัวระบบจะทำการ Build และอัปเดตหน้าเว็บจริงให้ภายในเวลาไม่กี่นาทีครับ
