# ตอนที่ 4: ESP32: เชื่อมต่อโลกอินเทอร์เน็ต (ตอนที่ 2)

ต่อยอดจากตอนที่แล้ว เราจะนำข้อมูลจากเซนเซอร์ส่งขึ้นสู่โลกออนไลน์

## เนื้อหาในตอนนี้

- การใช้ Blynk App บนมือถือ
- การแจ้งเตือนผ่าน LINE Notify
- การสร้าง Web Server อย่างง่ายเพื่อควบคุมอุปกรณ์

---

> [!CAUTION]
> การเชื่อมต่อ Cloud ต้องระวังเรื่องความปลอดภัยและ API Token ไม่ควรเปิดเผยให้คนอื่นทราบ
