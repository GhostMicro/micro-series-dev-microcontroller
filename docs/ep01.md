# ตอนที่ 1: โลกของ Microcontroller เลือกตัวไหนดี?

ในตอนนี้เราจะมาทำความรู้จักกับ Microcontroller แต่ละตระกูลที่นิยมใช้ในปัจจุบัน เพื่อให้คุณเลือกตัวที่เหมาะสมที่สุดกับโปรเจกต์ของคุณ

## เปรียบเทียบ Microcontroller ยอดนิยม

| บอร์ด            | จุดเด่น                                  | เหมาะสำหรับ                      |
| ---------------- | ---------------------------------------- | -------------------------------- |
| **Arduino**      | ใช้ง่ายที่สุด, Library เยอะมาก           | ผู้เริ่มต้น, โปรเจกต์ทั่วไป      |
| **ESP32**        | มี Wi-Fi/Bluetooth ในตัว, ราคาคุ้มค่า    | งาน IoT, ระบบไร้สาย              |
| **STM32**        | ประสิทธิภาพสูง, มาตรฐานอุตสาหกรรม        | งานโปรเฟสชันแนล, ควบคุมมอเตอร์   |
| **Raspberry Pi** | คือคอมพิวเตอร์จริงๆ (SBC), รัน Linux ได้ | งาน AI, Image Processing, Server |
