# ตอนที่ 6: Raspberry Pi: คอมพิวเตอร์จิ๋วที่ทำได้ทุกอย่าง

เปลี่ยนจาก Microcontroller (MCU) มาเรียนรู้ Single Board Computer (SBC) อย่าง Raspberry Pi

## เนื้อหาในตอนนี้

- ความต่างที่สำคัญ: MCU vs SBC
- การติดตั้ง Raspberry Pi OS (บน microSD Card)
- การใช้งาน Desktop และ Terminal เบื้องต้น

---

> [!NOTE]
> Raspberry Pi รันบนระบบปฏิบัติการ (Multi-tasking) ในขณะที่ Arduino รันเป็น Loop ทีละคำสั่ง
