# ตอนที่ 7: Raspberry Pi + Python: ควบคุม Hardware

มาเรียนรู้ความยืดหยุ่นของภาษา Python ในการควบคุมอุปกรณ์ฮาร์ดแวร์ภายนอกผ่านขา GPIO ของ Raspberry Pi

## เนื้อหาในตอนนี้

- ทำความรู้จักกับขา GPIO บน Raspberry Pi
- การเขียนโปรแกรม Python เบื้องต้น (RPI.GPIO หรือ gpiozero)
- โปรเจกต์รับค่าจากสวิตช์และสั่งงาน LED

---

> [!TIP]
> ห้องสมุด `gpiozero` ถูกออกแบบมาให้เขียนโค้ดได้กระชับและเข้าใจง่ายมาก เหมาะสำหรับผู้เริ่มต้น Python
